# Integration: AWS S3

## Source of truth
- S3 service: `src/aws/services/s3-bucket.service.ts`
- Tutorial/report assets: `src/tutorials/*`, `src/testkit-sample-reports/*`

## Required env vars
- `AWS_ACCESS_KEY`
- `AWS_SECRET_KEY`
- `AWS_REGION`
- `BUCKET_NAME`
- `S3_ENDPOINT`

## Notes
- Used for static assets and sample report downloads.
